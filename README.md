# Ahmad Khan — Portfolio

A responsive, single-page portfolio website built with HTML and CSS.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `ahmadkhan-datascientist.github.io`).
2. Upload `index.html` and the `assets` folder.
3. In repository Settings → Pages, select the main branch and root folder.
4. Save and wait for GitHub Pages to publish.

## Before publishing
- Verify the education dates and all project descriptions.
- Add direct GitHub repository links to each project card if available.
- Consider adding a downloadable PDF resume.
